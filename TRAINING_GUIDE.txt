U-NET BACKGROUND REMOVAL - TRAINING GUIDE
========================================

QUICK START
-----------
1. python train.py --mode test    # 5-10 minute test
2. python train.py --mode fast    # 1 hour training  
3. python inference.py --input photo.jpg --output result.png

TRAINING MODES
--------------
TEST MODE (5-10 minutes)
- 100 images, 3 epochs, 256x256 resolution
- Perfect for: Verifying setup works
- Command: python train.py --mode test

FAST MODE (30-60 minutes) 
- 2000 images, 10 epochs, 256x256 resolution
- Perfect for: Quick quality results
- Command: python train.py --mode fast

FULL MODE (2-4+ hours)
- All images, 20 epochs, 320x320 resolution  
- Perfect for: Maximum quality
- Command: python train.py --mode full

CUSTOM TRAINING
---------------
python train.py --epochs 15 --batch_size 8 --lr 0.0005 --subset 5000

Parameters:
--epochs      Number of training epochs
--batch_size  Images per batch (reduce if out of memory)
--lr          Learning rate (lower = more stable)
--subset      Use subset of images (faster training)

DATA PREPARATION
----------------
1. Images go in: data/images/
2. Masks go in: data/masks/
3. Files must have matching names:
   - image: photo001.jpg
   - mask:  photo001.png (or photo001.jpg)

EXPECTED TRAINING TIMES (CPU)
-----------------------------
Test Mode:    5-10 minutes
Fast Mode:    30-60 minutes  
Full Mode:    2-4 hours
Custom 50 epochs: 6-8 hours

EXPECTED TRAINING TIMES (GPU)
-----------------------------  
Test Mode:    1-2 minutes
Fast Mode:    5-10 minutes
Full Mode:    20-40 minutes
Custom 50 epochs: 1-2 hours

MONITORING TRAINING
-------------------
Watch for:
- Loss decreasing over epochs
- "Best model saved" messages
- Checkpoints saved every 5 epochs

Stop training if:
- Loss stops decreasing for many epochs
- You're happy with current quality
- You run out of time

USING TRAINED MODEL
-------------------
Single image:
python inference.py --input photo.jpg --output result.png

Batch process:
python inference.py --input photos/ --output results/ --batch

With custom settings:
python inference.py --input photo.jpg --threshold 0.7 --device cuda

TROUBLESHOOTING
---------------
"No images found":
- Check data/images/ folder exists
- Verify image files (.jpg, .png, .jpeg)

"Out of memory":
- Reduce batch size: --batch_size 2
- Reduce image size: add image_size=256 to train_unet()

"Poor quality results":
- Train longer: --epochs 30
- Use more data: add more images to data/images/
- Try different threshold: --threshold 0.3 or 0.7

"Training too slow":
- Use GPU: --device cuda
- Reduce images: --subset 1000
- Use test mode first

PERFORMANCE TIPS
----------------
Speed up training:
- Use GPU if available
- Increase batch size if you have RAM
- Use subset for testing
- Reduce image size to 256x256

Improve quality:
- Train more epochs
- Use full resolution (320x320)
- Add more training data
- Use lower learning rate

BEST PRACTICES
--------------
1. Always start with test mode
2. Use fast mode for good results quickly
3. Only use full mode if you need best quality
4. Monitor training - stop if loss plateaus
5. Save good checkpoints before experimenting
6. Test on different images to verify quality
