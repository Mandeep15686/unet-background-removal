U-NET BACKGROUND REMOVAL - COMMAND REFERENCE
===========================================

SETUP COMMANDS
--------------
Windows:     setup.bat
Linux/Mac:   bash setup.sh
Manual:      pip install -r requirements.txt

TRAINING COMMANDS
-----------------
Quick test (5-10 min):
python train.py --mode test

Fast training (1 hour):
python train.py --mode fast

Full training (4+ hours):
python train.py --mode full

Custom training:
python train.py --epochs 20 --batch_size 4 --lr 0.001 --subset 5000

Resume training:
python train.py --resume checkpoints/checkpoint_epoch_10.pth

INFERENCE COMMANDS
------------------
Single image:
python inference.py --input photo.jpg --output result.png

Batch process folder:
python inference.py --input photos/ --output results/ --batch

With custom threshold:
python inference.py --input photo.jpg --threshold 0.7

Using GPU:
python inference.py --input photo.jpg --device cuda

USEFUL PARAMETER COMBINATIONS
-----------------------------
Fast test with custom data:
python train.py --epochs 5 --batch_size 2 --subset 500

High quality training:
python train.py --epochs 30 --batch_size 8 --lr 0.0005

Memory-efficient training:
python train.py --epochs 15 --batch_size 2

Speed-optimized inference:
python inference.py --input folder/ --batch --device cuda --threshold 0.5

MONITORING AND DEBUGGING
------------------------
Check training progress:
- Watch console output for loss values
- Check checkpoints/ folder for saved models
- Monitor runs/ folder for logs

Test model quality:
python inference.py --input test_image.jpg --output test_result.png

FOLDER STRUCTURE COMMANDS
-------------------------
Create data folders:
mkdir data/images data/masks checkpoints outputs runs

List training images:
ls data/images/ | head -10    # Linux/Mac
dir data\images | head -10   # Windows

Count training files:
ls data/images/ | wc -l       # Linux/Mac  
dir data\images | find /c /v ""  # Windows

FILE MANAGEMENT
---------------
Copy training data:
cp /path/to/images/* data/images/     # Linux/Mac
cp /path/to/masks/* data/masks/       # Linux/Mac

Backup models:
cp checkpoints/best_model.pth backups/model_backup.pth

Clean up old checkpoints:
rm checkpoints/checkpoint_epoch_*.pth  # Keep only best_model.pth

COMMON WORKFLOWS
----------------
First time setup:
1. setup.bat (or setup.sh)
2. Add images to data/images/ and data/masks/
3. python train.py --mode test
4. python inference.py --input photo.jpg

Daily usage:
1. python inference.py --input new_photo.jpg
2. python inference.py --input photo_folder/ --batch

Improve model:
1. Add more training data
2. python train.py --mode full
3. Test with: python inference.py --input test.jpg

QUICK REFERENCE
---------------
Test setup:         python train.py --mode test
Train model:        python train.py --mode fast
Remove background:  python inference.py --input photo.jpg
Batch process:      python inference.py --input folder/ --batch
Use GPU:           Add --device cuda to any command
Reduce memory:     Add --batch_size 2 to training
Speed up:          Add --subset 1000 to training
Custom quality:    Add --threshold 0.7 to inference

Remember: Always test with --mode test first!
